# 家庭课外课程记录与管理系统

一个简洁易用的本地课程管理工具，专为家庭课外课程记录而设计。支持多学员管理、日历视图展示和数据统计分析。

## 功能特性

### 📚 核心功能
- **课程记录管理** - 快速添加、编辑、删除课程记录
- **日历视图** - 直观的月视图界面，一目了然查看课程安排
- **多学员支持** - 支持家庭多个成员的课程管理
- **数据统计** - 多维度统计分析，了解学习情况
- **本地存储** - 所有数据保存在本地，保护隐私安全

### 🎯 详细功能

#### 1. 课程记录功能
- **添加记录**：包含日期、学员、课程名称、备注等字段
- **编辑功能**：点击任意记录可进行修改
- **删除功能**：支持删除不需要的记录
- **表单验证**：确保数据完整性

#### 2. 日历视图
- **月视图展示**：清晰的日历布局
- **课程标记**：不同颜色圆点标识不同学员
- **日期详情**：点击日期查看当日所有课程
- **今日高亮**：当前日期特殊标识
- **月份导航**：便捷的前后月份切换

#### 3. 统计分析
- **概览统计**：总课程数、活跃学员数、课程类型数
- **筛选功能**：按学员、时间范围筛选
- **详细报表**：按学员和课程的详细统计表格
- **趋势分析**：了解课程参与情况

#### 4. 学员管理
- **添加学员**：支持自定义学员姓名
- **删除学员**：灵活的学员管理
- **颜色标识**：每个学员有独特的颜色标识

#### 5. 数据管理
- **数据导出**：支持JSON格式导出
- **数据导入**：支持从文件恢复数据
- **数据备份**：本地存储自动保存
- **数据重置**：一键清空所有数据

### 快速上手

#### 第一次使用
1. 打开系统后，默认显示日历视图
2. 系统已预置3个学员（我、孩子A、孩子B）和一些示例数据
3. 点击右下角的⚙️设置按钮可以管理学员

#### 添加课程记录
1. 点击顶部"添加课程"按钮
2. 选择日期（默认为今天）
3. 选择学员
4. 输入课程名称（如：钢琴课、游泳课、编程课）
5. 添加备注（记录课程内容、老师点评等）
6. 点击"保存课程"

#### 查看课程安排
1. 在日历视图中，有课程的日期会显示彩色圆点
2. 不同颜色代表不同学员
3. 点击任意日期查看当日课程详情
4. 点击课程记录可以进行编辑

#### 查看统计数据
1. 点击顶部"统计分析"按钮
2. 使用筛选器选择特定学员或时间范围
3. 查看概览卡片了解整体情况
4. 查看详细表格了解具体统计

## 使用技巧

### 快捷键
- `Ctrl/Cmd + N`: 快速添加新课程
- `Ctrl/Cmd + S`: 在表单中快速保存
- `Esc`: 关闭打开的弹窗

### 学员管理
- 在设置中可以添加新学员或删除现有学员
- 每个学员都有独特的颜色标识
- 删除学员不会删除相关的课程记录

### 数据管理
- **定期备份**：建议定期使用"导出数据"功能备份
- **数据迁移**：可以通过导出/导入功能在不同设备间迁移数据
- **数据安全**：所有数据存储在浏览器本地，清除浏览器数据会丢失记录

### 最佳实践
1. **及时记录**：课程结束后尽快记录，避免遗忘
2. **详细备注**：在备注中记录重要信息，如作业、进度、老师评价
3. **定期查看统计**：通过统计功能了解课程参与情况
4. **定期备份**：重要数据请定期导出备份

## 故障排除

### 常见问题

**Q: 数据丢失了怎么办？**
A: 检查是否清除了浏览器数据。如果有备份文件，可以通过"导入数据"功能恢复。

**Q: 日历不显示课程？**
A: 检查课程记录的日期格式是否正确，刷新页面试试。

**Q: 无法添加学员？**
A: 确保学员姓名不为空且不重复。

**Q: 页面显示异常？**
A: 尝试刷新页面，或检查浏览器兼容性。

### 浏览器兼容性
- Chrome 60+
- Firefox 55+
- Safari 10+
- Edge 15+

### 性能优化
- 建议定期清理过旧的课程记录（可通过导出后删除实现）
- 大量数据时可能影响性能，建议分时段管理

## 技术说明

### 技术栈
- **前端**：HTML5、CSS3、JavaScript (ES6+)
- **存储**：localStorage（浏览器本地存储）
- **样式**：响应式设计，支持移动设备
- **图标**：Font Awesome 6.0

### 数据存储
- 使用浏览器的 localStorage 存储数据
- 数据格式为 JSON
- 包含课程记录和学员信息两个主要数据集

### 隐私保护
- 所有数据存储在本地，不会上传到服务器
- 无需网络连接即可使用
- 无数据收集和追踪
